2. Phase 2：左侧导航。
3. Phase 3：中间内容区基础信息。
4. Phase 4：列表视图。
5. Phase 7：右侧详情面板。
6. Phase 5：网格视图。
7. Phase 6：紧凑视图。
8. Phase 8：过滤、搜索、排序。

列表视图和右侧详情面板建议优先于网格视图，因为它们决定数据结构和交互状态。网格视图、紧凑视图可以复用同一套 mock 数据和 selection state。
