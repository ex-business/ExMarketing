# Task

## 标题

管理后台页面

## 需求 ID

2026-05-24-113400-11

## 背景

来源：22-独立活动营销中台设计。补齐活动配置、规则配置、奖励配置、预算库存、互斥叠加、风控、发奖方式、审批流、模拟运行、操作审计页面。验收：页面不再为每个活动单独堆一套，通用组件可配置多种活动。

## Owner 补充决策

### 本期范围

本期只交付“当前后端 API 已支持或已在本工程明确存在的本地管理页面”。

审批流、上线发布、活动编辑发布、复制、删除、暂停、恢复、结束、版本回滚属于后续独立任务。本期页面可以展示入口或占位状态，但必须禁用这些操作，不允许伪造成功，不允许用前端状态假装后端已经支持。

本期页面定位为本地开发 / 内网管理台，不作为公网生产 Admin。

### 本期可执行页面

- 活动列表。
- 新增活动。
- 活动详情只读展示。
- Quota 创建和展示。
- 模拟运行。
- 审计记录查询。
- 当前 git diff / Agent 工作台相关页面。
- 已有 API 可返回的事件、Fact Query、Callback、对账或 DLQ 相关只读/操作能力；如果后端接口不存在，页面必须禁用并展示“待后端接入”。

### 审批与上线

审批流和上线发布不在本期实现范围内。

本期规则：

- 不提供可点击成功的提交审批、审批通过、审批拒绝、撤回、上线、下线、版本回滚。
- 如果展示审批/上线区域，只能展示禁用状态和待接入说明。
- 不能在前端本地改状态模拟审批成功。
- 不能把静态 mock 当作真实后端结果。

### 活动编辑发布

活动编辑、复制、删除、暂停、恢复、结束、版本回滚不在本期实现范围内。

本期只允许：

- 通过现有 `POST /admin/v1/activities` 创建活动。
- 通过现有列表/详情能力查看活动。
- 展示后端返回的真实状态。

### 错误处理

所有页面操作必须展示后端真实错误原因。接口不存在、接口返回非 2xx、校验失败、状态冲突时，页面必须显示失败，不得显示成功。

## 目标

- 建立通用管理后台页面，不再为每类活动堆独立页面。
- 支持当前已有后端能力的可视化配置、查询、模拟和审计。
- 对未接入的审批、上线、编辑发布能力做明确禁用和待接入展示。

## 范围

- 活动列表和新增活动。
- 活动配置、规则配置、奖励配置、预算库存、互斥叠加、风控、发奖方式的展示和当前后端允许的录入。
- Quota 创建和展示。
- 模拟运行页面。
- 操作审计页面。
- 后端错误展示。
- 未接入能力的禁用状态和待接入说明。

## 非目标

- 审批流后端接口。
- 上线发布后端接口。
- 活动编辑、复制、删除、暂停、恢复、结束、版本回滚后端接口。
- 公网生产 Admin 鉴权。
- 完整 RBAC。
- 使用前端 mock 伪造后端成功。

## 风险等级

中

## 验收标准

- 页面能打开并加载活动列表。
- 页面能通过现有 API 新增活动，并展示后端返回结果。
- 页面能创建或展示 quota，并正确表达缺失 quota 为 unlimited。
- 页面能发起模拟运行并展示命中/未命中原因、规则解释、奖励预览、预算库存影响和发奖指令预览；如果后端能力不足，必须显示待接入或真实错误。
- 页面能展示审计记录。
- 页面所有失败操作都展示后端错误原因。
- 审批、上线、活动编辑发布、复制、删除、暂停、恢复、结束、版本回滚入口必须禁用或标注待接入，不能显示为已成功执行。
- 页面不按具体活动类型硬编码独立页面，通用组件可配置多种活动。
