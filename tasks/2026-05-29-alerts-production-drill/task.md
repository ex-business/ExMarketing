# Task

## 标题

alerts-production-drill: 生产告警演练与故障注入

## 需求 ID

2026-05-29-alerts-production-drill

## 背景

告警配置必须通过演练验证。需要在本地或测试环境模拟 worker 停止、DB 慢查询、outbox 堆积、DLQ 增长、callback 失败等场景，确认告警触发、通知、恢复和复盘流程可用。

## 目标

- 建立可重复执行的告警演练脚本或步骤。
- 故障注入后能观测指标变化和告警触发。
- 恢复后告警自动恢复或可人工关闭。
- 演练报告记录时间线、指标、通知和修复动作。

## 范围

- Worker 停止或不消费。
- Outbox backlog 堆积。
- DLQ count 增长。
- Callback 失败率升高。
- DB 慢查询/连接失败。
- Quota 扣减冲突或失败率升高。

## 交付物

- 故障注入脚本或操作手册。
- 演练数据准备和清理步骤。
- 演练报告模板。
- 至少一轮本地/测试环境演练记录。

## 非目标

- 不在生产环境直接做破坏性演练。
- 不做混沌工程平台。
- 不模拟外部发奖系统真实资金行为。

## 风险等级

高

## 验收标准

- 每个核心故障场景都有触发、观测、恢复步骤。
- 告警触发和恢复时间可记录。
- 演练不会污染长期测试数据。
- 失败场景有复现日志。
