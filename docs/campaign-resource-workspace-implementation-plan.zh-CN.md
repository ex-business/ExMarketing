# Campaign Editor 资源页重构实施拆解

Date: 2026-06-29
Scope: `frontend/admin-flow/src/CampaignEditorPage.tsx`, `CampaignEditorPage.css`, `frontend/admin-flow/e2e/campaign-editor.spec.ts`

## 目标

按照用户提供的资源页截图，把 Campaign Editor 的 `资源` 工作区从卡片式资源中心重构为蓝白简洁的表格型管理台。

## 信息架构

一级导航保持：

- 页面
- 资源
- 设置
- 模板库

资源页内部结构：

- 顶部紧凑工具栏：标题、搜索、来源筛选、状态筛选、添加按钮。
- 左侧资源类型树：按数据字段、数据源、动作事件、样式 Token、图片素材展示子类和数量，并作为资源类型切换入口。
- 中间资源表格：当前 tab 的资源列表，选中行高亮。
- 右侧详情/新增面板：查看资源详情，或在新增态填写表单。

## 分解任务

1. 资源数据模型
   - 定义资源 tab：`数据`、`数据源`、`动作`、`样式`、`图片`。
   - 为每个 tab 提供表格列所需字段。
   - 数据源支持接口地址、请求方式、刷新策略、最近延迟、字段映射。
   - 图片资源支持缩略图、用途、尺寸、大小。

2. 顶部工具栏
   - 不放资源类型 tab，避免和左侧资源类型树重复。
   - 搜索、来源、状态筛选保持单行。
   - `+ 添加` 根据当前左侧选中的资源类型进入新增态。

3. 左侧资源类型树
   - 展开/收起资源类型。
   - 一级资源类型负责切换当前资源表格。
   - 子类过滤当前资源类型表格。
   - 当前选中子类浅蓝高亮。

4. 中间表格
   - 非卡片式。
   - 行高紧凑、分割线清晰。
   - 选中行使用浅蓝背景和左侧蓝线。
   - 新增态在表格顶部插入新增行。

5. 右侧面板
   - 详情模式：显示当前资源的基本信息、引用、使用方式。
   - 新增模式：根据 tab 显示不同表单。
   - 数据：字段名称、字段类型、数据来源、默认值、绑定组件、说明、表达式预览。
   - 数据源：数据源名称、数据源类型、接口地址、请求方式、来源类型、刷新策略、字段映射、实时拉取预览。
   - 动作：动作名称、动作类型、触发组件、白名单、Payload Schema、说明、验证结果。
   - 样式：样式名称、Token、类型、默认值、适用组件、状态、样式预览。
   - 图片：批量上传图片、上传队列表格、用途、推荐尺寸、状态、删除、全部保存。

6. 图片批量上传
   - UI 支持拖拽/点击选择文件。
   - 队列表格展示文件名、用途、推荐尺寸、状态、操作。
   - 显示批量统计：已选择、总大小、尺寸不匹配数量。
   - 保存按钮文案为 `全部保存`。

7. 数据源管理
   - 管理活动页运行时数据接口，例如 Activity View Model API、WebSocket 实时库存、用户资料接口。
   - 支持配置 REST API / GraphQL / WebSocket / Mock JSON。
   - 支持刷新策略：页面加载、手动刷新、30s 轮询、WebSocket 实时。
   - 右侧详情展示实时拉取预览，说明接口返回如何映射为页面可绑定字段。

8. 测试验收
   - 顶部不显示资源类型 tab。
   - 左侧资源类型树支持展开/收起，并负责切换资源类型。
   - 资源页没有卡片网格和指标 header。
   - 数据源 tab 显示接口列表、接口详情、实时拉取预览。
   - 数据/动作/样式新增态显示顶部新增行和右侧表单。
   - 数据源新增态显示顶部新增行和右侧接口配置表单。
   - 图片新增态显示批量上传队列和全部保存。
   - 搜索过滤资源表格。

## 非目标

- 不接真实上传 API。
- 不实现真实持久化。
- 不改变页面设计画布、模块预览、发布预览逻辑。
