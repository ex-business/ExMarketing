# Task

## 标题

security-release-gate-report: 安全发布门禁与审计报告

## 需求 ID

2026-05-29-security-release-gate-report

## 背景

安全审计需要落到发布流程，否则报告无法阻止高危问题上线。需要建立发布前安全 checklist、自动检查项、审计报告模板和风险接受流程。

## 目标

- 定义发布前安全门禁：PASS/BLOCK/WARN。
- 集成依赖漏洞扫描、配置基线检查、敏感信息扫描、测试结果和威胁模型结果。
- 高危问题必须阻断发布。
- 风险接受必须记录责任人、原因、补偿措施和到期时间。

## 范围

- Checklist：鉴权、签名、tenant guard、secret、日志脱敏、DLQ 操作、导出/备份、metrics 隐私。
- 自动检查：go test、go build、secret scan、依赖漏洞扫描或占位命令、配置校验。
- 报告：版本、commit、环境、检查结果、风险项、接受项、负责人。
- 流程：生成报告、人工确认、归档。

## 交付物

- 安全发布 checklist 文档。
- 审计报告模板。
- 可运行的门禁脚本或命令集合。
- 风险接受记录格式。

## 非目标

- 不替代公司统一 CI/CD。
- 不保证第三方渗透测试结果。
- 不允许高危风险无期限接受。

## 风险等级

高

## 验收标准

- 发布前能生成 PASS/BLOCK 报告。
- P0/P1 安全问题默认 BLOCK。
- 风险接受必须有 owner 和截止时间。
- 报告能追溯 commit、检查命令和结果。
- `go test ./...` 通过。
